# Технічна платформа TPS360

**Статус: заплановано.** Цей каталог стане місцем для реалізації цифрових модулів TPS360. Наразі він містить лише структурний каркас; програмний код і інтеграції ще не створені.

## Модулі

- `core` — спільні доменні моделі, правила та сервіси;
- `simulation` — підтримка проведення симуляцій;
- `assessment` — оцінювання готовності;
- `analytics` — аналітика та звітність;
- `api` — інтерфейси взаємодії між компонентами;
- `web` — вебінтерфейс;
- `mobile` — мобільний досвід;
- `ai` — контрольовані AI-можливості.
