# Архітектура TPS360

**Версія:** 0.1 · **Статус:** цільова концептуальна архітектура, не реалізація.

## Архітектурне бачення

TPS360 проєктується як модульна платформа з чіткими межами між доменною логікою, симуляціями, оцінюванням, аналітикою, інтерфейсами та AI-підтримкою. Модулі взаємодіють через документовані API; жоден інтерфейс не має обходити правила доступу або модель даних.

## Контейнери

| Модуль | Відповідальність |
| --- | --- |
| `platform/core` | спільні сутності: громада, користувач, роль, сесія, артефакт, доступ |
| `platform/simulation` | сценарії, події, ролі, проведення сесій і дебрифінг |
| `platform/assessment` | інструменти оцінювання, докази та профіль готовності |
| `platform/analytics` | агрегування, показники, звіти й візуалізація прогресу |
| `platform/api` | контракти інтеграції, автентифікація, авторизація й версіонування |
| `platform/web`, `platform/mobile` | користувацькі інтерфейси з доступним дизайном |
| `platform/ai` | допоміжні функції з наглядом людини та журналюванням |

## Дані й безпека

Модель даних має розділяти ідентифікаційні дані, операційні артефакти та агреговану аналітику. Застосовуються мінімізація даних, рольовий доступ, журналювання подій, строк зберігання та можливість експорту/видалення відповідно до майбутньої політики. Чутливі сценарії не повинні містити реальних персональних даних без правової підстави.

## Інтеграційні правила

API мають бути версіонованими, перевіряти права доступу і повертати зрозумілі помилки. Подієві записи симуляцій відокремлюються від висновків дебрифінгу. Аналітика споживає лише дозволені, мінімізовані дані. AI-модуль не отримує більше контексту, ніж потрібно для конкретної задачі.

## Нефункціональні вимоги

Пріоритети: безпека, доступність, зрозумілість, відмовостійкість, аудитованість і робота за нестійкого зв’язку. Конкретні технології, SLO, сховища та хмарні постачальники ще не обрані.

## Архітектурне врядування

Суттєві рішення фіксуються в `docs/adr/`. Зміни контрактів, даних або моделей оцінювання потребують рецензії відповідальних за методологію, безпеку й технічну архітектуру.
