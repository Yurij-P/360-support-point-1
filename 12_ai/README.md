# AI-компоненти

**Статус: дослідження.** Можливі напрями: підтримка підготовки сценаріїв, навігація базою знань, аналіз агрегованого зворотного зв’язку та персоналізація навчання.

Жоден AI-компонент не реалізований. Перед розробкою мають бути визначені межі застосування, нагляд людини, захист даних і критерії оцінювання ризиків.
