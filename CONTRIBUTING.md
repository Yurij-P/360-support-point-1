# Внесок у TPS360

Дякуємо за інтерес до розвитку TPS360. Проєкт перебуває на концептуальній стадії, тому пропозиції мають відокремлювати підтверджені рішення від гіпотез і планів.

## Принципи

- Пишіть українською мовою, якщо інше не потрібно для технічної сумісності.
- Не подавайте запланований функціонал як готовий або валідований.
- Не додавайте персональні, чутливі чи конфіденційні дані.
- Узгоджуйте зміни методології, сценаріїв та індикаторів із відповідальними за відповідний напрям.

## Робочий процес

1. Створіть окрему гілку з короткою змістовною назвою.
2. Опишіть мету зміни та її статус: концепція, чернетка, пілот чи затверджений матеріал.
3. Оновіть пов’язану документацію та перевірте посилання.
4. Відкрийте pull request із коротким описом, обмеженнями та потребами в рецензуванні.

## Якість

Для кожного нового артефакту додайте власника, дату перегляду, джерела або припущення та критерії готовності, якщо вони застосовні.
