# AGENTS.md

## Призначення

Цей файл задає базові правила для AI-агентів і контриб’юторів, які працюють у репозиторії **TPS360 / «Точка підтримки 360»**.

## Обов’язково прочитати перед будь-якими змінами

1. `MASTER_PROJECT.md`
2. `SKILL.md`
3. `README.md`
4. `CONTRIBUTING.md`

Якщо `MASTER_PROJECT.md` відсутній або вимоги конфліктують — зупиніться і запросіть уточнення.

## Ключові правила роботи

- Працюйте українською мовою, якщо немає технічної потреби інакше.
- Не подавайте концепти, чернетки чи пілоти як завершений або валідований продукт.
- Не додавайте персональні, чутливі або конфіденційні дані.
- Не вигадуйте нові ролі, ієрархії, права доступу чи ресурси без явного погодження.
- Узгоджуйте зміни з наявними вимогами, а не з припущеннями.
- Вносьте малі, цільові зміни; не зачіпайте не пов’язані частини репозиторію.

## Орієнтири по структурі

- `01_governance` … `16_tests`: тематичні розділи проєкту.
- `src/tps360`: Python-код доменної моделі та API.
- `docs`: додаткова документація.

## Перевірки перед завершенням

Використовуйте наявні команди репозиторію:

```bash
make test
make lint
make typecheck
git diff --check
git status --short --branch
```

Якщо якась перевірка не запускається, зафіксуйте причину у звіті.

## Очікуваний формат змін

- Чітко вказуйте: що змінено, чому, і до якого затвердженого джерела це прив’язано.
- Для змін у документації підтримуйте узгодженість між пов’язаними файлами.
- У PR описуйте обмеження та питання, що потребують рев’ю.
