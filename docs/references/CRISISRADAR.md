# Референс: CrisisRadar (NL) — порівняння з потребами TPS360

**Джерело:** https://crisisradar.com/uk (переглянуто 2026-07-27)
**Призначення:** зовнішня платформа-орієнтир для звірки, що потрібно TPS360. Це не
конкурент у тій самій ніші й не джерело даних — це зрілий продукт із суміжної
області, з якого варто взяти найкращі ідеї.

## Що таке CrisisRadar

Нідерландська AI-платформа кризового управління для регіонів безпеки,
муніципалітетів, лікарень, операторів мереж, критичної інфраструктури та МСБ.
Модель «магазину додатків»: підключаєш лише потрібні модулі.

**Життєвий цикл (4 фази):** Підготовка → Виявлення → Реагування → Оцінка.

- **Підготовка:** кризові плани, готові сценарії, Business Impact Analysis (BIA),
  ІКТ-план відновлення (DRP). Відповідність ISO 22301 / NIS2.
- **Виявлення:** моніторинг новин, соцмереж, урядових сповіщень (NL-Alert) → єдина
  «кризова картина».
- **Реагування:** AI складає повідомлення під кожну аудиторію/канал за секунди
  (методологія CRASSU); сповіщення команди (SMS/email).
- **Оцінка:** автоматичні звіти, покриття ISO 22301, вразливості, планування навчань.
- **Мережа експертів** (юридичні, кібербезпека, HR, психосоціальна допомога).
- **Безкоштовні фасилітовані кризові навчання.**
- **Інтеграції:** бізнес-дані (KvK), новини/RSS, NL-Alert, соцмережі (Coosto),
  M365, Google Workspace.
- Комплаєнс: GDPR, ISO 22301, локальний ШІ, дані в межах країни.

## Паралелі з TPS360

| Аспект | CrisisRadar | TPS360 |
|---|---|---|
| Життєвий цикл | Підготовка/Виявлення/Реагування/Оцінка | Підготовка → симуляція → дебрифінг (AAR) |
| AI на фактах | так (CRASSU) | так (`EmpiricalCrisisIncidentFact`, OSINT feeds) |
| Фасилітовані навчання | так (реальні) | так (рольова симуляція під фасилітатором) |
| Аудиторія | муніципалітети, критична інфраструктура | територіальні громади, ОМС |
| Модульність | магазин додатків | модулі домену (community/threat/simulation/…) |
| Оцінка/звіти | авто-звіт + ISO 22301 | AAR + телеметрія (`AARTelemetryService`) |

## Що варто перейняти (для наших потреб)

1. **BIA — Business Impact Analysis:** карта критичних процесів громади та час
   відновлення. Добре лягає на паспорт громади + ресурсну модель (`TPS360-RES-001`).
2. **Фаза «Виявлення» (моніторинг):** підключення новин/офіційних сповіщень у
   «кризову картину» — узгоджується з нашим реєстром джерел
   ([`../data-sources/AI-DATA-SOURCES.md`](../data-sources/AI-DATA-SOURCES.md)).
3. **AI-комунікація під аудиторії:** генерація повідомлень для різних цільових груп
   (мешканці, ЗМІ, служби) — потенційний модуль для фази реагування.
4. **Прив'язка до стандарту (ISO 22301):** ідея вимірювати «покриття стандарту»
   наживо — аналог для наших методичних стандартів TPS360-*.
5. **Модульність / «магазин»:** підтверджує наш підхід розділених доменних модулів.

## Чого НЕ переймаємо / межі

- CrisisRadar орієнтований на **реальну** оперативну комунікацію в кризу; TPS360 —
  насамперед **навчально-симуляційна** платформа для громад України.
- Специфіка NL (NL-Alert, KvK, ISO/NIS2) — не наш контекст; наш контекст — КАТОТТГ,
  OSM, ДСНС, воєнні реалії.
- Це не джерело даних для AI — не додавати в реєстр джерел.
