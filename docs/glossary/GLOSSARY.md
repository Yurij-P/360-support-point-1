# Глосарій TPS360

| Термін | Визначення |
| --- | --- |
| **TPS360** | Інтегрована платформа підготовки та моделювання кризових ситуацій для громад і ГО. |
| **Громада** | Територіальна громада або її уповноважена команда, що бере участь у підготовці чи пілоті. |
| **Готовність** | Спроможність громади передбачати, готуватися, реагувати, відновлюватися та навчатися в контексті криз. |
| **Симуляція** | Безпечне моделювання кризової ситуації для відпрацювання взаємодії та рішень. |
| **Сценарій** | Версіонований опис контексту, ролей, подій, цілей і матеріалів симуляції. |
| **Дебрифінг** | Структуроване обговорення після симуляції для осмислення рішень, доказів і наступних кроків. |
| **AAR (After Action Review)** | Огляд після дії: запис очікувань, фактичних подій, причин розбіжностей і покращень. |
| **CPI (Community Preparedness Index)** | Запланований індекс готовності громади, який агрегує підтверджені виміри без підміни професійного висновку. |
| **CPMM (Community Preparedness Maturity Model)** | Модель зрілості готовності громади з рівнями розвитку спроможностей. |
| **CPP (Community Preparedness Profile)** | Профіль готовності громади: контекстуалізований опис сильних сторін, прогалин, доказів і пріоритетів. |
| **AI (Artificial Intelligence)** | Допоміжні алгоритмічні можливості, що діють під наглядом людини та не ухвалюють остаточних рішень. |
