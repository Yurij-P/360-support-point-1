# Глосарій TPS360

Цей каталог призначений для узгоджених визначень термінів, скорочень і понять, що використовуються в матеріалах TPS360.

**Статус: стартовий каркас.** Визначення ще не затверджені та мають проходити методологічний і редакційний перегляд.

## Правила ведення

- Один термін — одне основне визначення з посиланнями на джерела або пов’язані документи.
- Позначайте дату перегляду та відповідального за запис.
- Уникайте неоднозначних скорочень; при першому використанні розшифровуйте їх.
- Додавайте англомовний відповідник лише за потреби сумісності або посилань на джерела.
