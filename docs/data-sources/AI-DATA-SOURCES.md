# Джерела даних для підживлення AI (AI grounding sources)

**Статус:** живий реєстр (наповнюється).
**Призначення:** перелік перевірених зовнішніх джерел, якими заземлюється AI Crisis
Copilot та наповнюється паспорт громади. Узгоджено з `ai_crisis_copilot`
(`EmpiricalCrisisIncidentFact`, `official_sources_feed`), `ADR-0008` (паспорт/межі
громади), `ADR-0014` (КАТОТТГ) і `TPS360-RES-001` (виведення ресурсів з даних).

> Правило: AI не вигадує подій — він спирається лише на перевірені джерела. Кожне
> джерело перед використанням маркується рівнем довіри та способом доступу.

## Кандидати на додавання (перевірити)

- Офіційні дані ДСНС України (оперативні зведення, типи НС).
- Офіційний КАТОТТГ-довідник (`directory.org.ua`) — уже інтегровано в каталог громад.
- OpenStreetMap (межі, критична інфраструктура) — уже використовується (`osm_map_viewer`).
- Норми ресурсного забезпечення (ДСНС/МОЗ/ДБН) — для нормативної оцінки endowment (Фаза 1).

## Як додавати джерело

1. Зазначити тип даних і що конкретно з них береться.
2. Спосіб доступу: відкритий API / датасет (CSV/JSON) / скрапінг / ручне
   вивантаження / за запитом.
3. Рівень довіри (офіційне відомство, OSINT, ЗМІ) та ліцензію/умови використання.
4. Куди підключається в TPS360 (паспорт, факти AI, ресурси, сценарії).
5. Статус: 🔎 до перевірки · ✅ підключено · ⛔ відхилено.
