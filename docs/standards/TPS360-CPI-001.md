# TPS360-CPI-001 — Індекс готовності громади (CPI)

**Версія:** 0.1 · **Статус:** базовий стандарт Foundation · **Власник:** команда оцінювання.

## Мета

Встановити принципи майбутнього CPI — інструменту узагальнення даних про готовність громади.

## Норми

1. CPI вимірює спроможності та прогрес, а не «цінність» громади.
2. Кожен показник має визначення, джерело, період, метод розрахунку й обмеження.
3. Індекс не може бути єдиною підставою для фінансування, санкцій чи публічних рейтингів.
4. Порівняння можливе лише за сумісних контекстів, методів і якості даних.
5. Разом з числом CPI публікується CPP, діапазон невизначеності та пояснення.

## Статус моделі

Формула CPI у v0.1 не затверджена й не повинна використовуватися для реальних оцінок.
