# TPS360-CPP-001 — Профіль готовності громади (CPP)

**Версія:** 0.1 · **Статус:** базовий стандарт Foundation · **Власник:** команда оцінювання.

## Мета

Визначити мінімальний склад CPP — контекстуального профілю готовності громади.

## Норми

1. CPP містить контекст, сильні сторони, прогалини, докази, ризики та пріоритети покращення.
2. Кожен висновок має джерело, дату та рівень упевненості.
3. Профіль погоджується з уповноваженими представниками громади до зовнішнього поширення.
4. Публічна версія виключає чутливі дані та операційні деталі.
5. CPP переглядається після істотних змін контексту, навчання або пілотної симуляції.

## Зв’язок

CPP пояснює CPI та CPMM: числа й рівні не мають трактуватися без відповідного профілю.
