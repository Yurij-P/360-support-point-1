# TPS360-CPMM-001 — Модель зрілості готовності громади (CPMM)

**Версія:** 0.1 · **Статус:** базовий стандарт Foundation · **Власник:** команда оцінювання.

## Мета

Визначити правила майбутньої моделі зрілості, що допомагає громадам планувати розвиток спроможностей.

## Норми

1. CPMM описує розвиток у вимірах, а не встановлює єдиний універсальний шлях.
2. Рівень зрілості підтверджується доказами: практиками, артефактами, результатами навчання або перевірок.
3. Самооцінка відокремлюється від зовнішньої верифікації.
4. Модель враховує контекст, ресурси та обмеження громади.
5. Рівні не використовуються для стигматизації чи спрощених рейтингів.

## Статус моделі

Перелік вимірів і рівнів має бути сформований та перевірений у пілотах.
