# ADR-0001: Модульна архітектура TPS360

**Статус:** прийнято для Foundation v0.1 · **Дата:** 2026-07-24

## Контекст

TPS360 поєднуватиме методологію, симуляції, оцінювання, аналітику та навчання. Монолітна структура без меж модулів ускладнить безпечну еволюцію, тестування й адаптацію до пілотів.

## Рішення

Прийнято модульну цільову архітектуру з `core`, `simulation`, `assessment`, `analytics`, `api`, `web`, `mobile` та `ai`. Взаємодія відбувається через версіоновані контракти API; доменні правила та доступ не дублюються в інтерфейсах.

## Альтернативи

- Єдиний моноліт: відхилено через високий ризик зв’язності та складність незалежного розвитку.
- Набір незалежних сервісів з початку: відхилено як передчасно складний для Foundation.

## Наслідки

Потрібні чіткі контракти, ADR для міжмодульних рішень і дисципліна володіння даними. Технологічний стек буде обрано окремим ADR.
