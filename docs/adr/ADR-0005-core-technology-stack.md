# ADR-0005: Python стек ядра

**Статус:** прийнято · **Дата:** 2026-07-24

Використовуємо Python 3.12+, FastAPI, Pydantic v2, SQLAlchemy 2, Alembic, PostgreSQL як цільове сховище, SQLite для локальних тестів, pytest, ruff і mypy. Це дає типізований API та шлях до міграцій без передчасної реалізації інфраструктури.
