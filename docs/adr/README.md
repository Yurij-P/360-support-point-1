# ADR — Architecture Decision Records

Цей каталог зберігатиме короткі записи про суттєві рішення TPS360: контекст, обране рішення, альтернативи, наслідки й статус.

**Статус: стартовий каркас.** Жодного ADR ще не затверджено.

## Іменування

Використовуйте формат `NNNN-коротка-назва.md`, наприклад `0001-модель-версіонування-документації.md`.

## Мінімальна структура ADR

1. Статус;
2. Контекст;
3. Рішення;
4. Альтернативи;
5. Наслідки;
6. Дата та відповідальний.
