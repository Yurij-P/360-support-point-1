# ADR-0008: Геопросторові симуляції для конкретної громади

**Статус:** прийнято для Sprint 2A · **Дата:** 2026-07-24

## Context

TPS360 потребує відтворюваної моделі симуляції, прив’язаної до конкретної громади, її меж, локальних ризиків, перевіреної інфраструктури та ресурсів.

## Decision

Кожна симуляція створюється для конкретної громади на основі її цифрового профілю та версіонованої геопросторової карти. OpenStreetMap (OSM) використовується як базова карта й джерело відкритих об’єктів. Внутрішні дані TPS360 та OSM-дані зберігаються логічно окремо.

## Alternatives

- Єдина узагальнена карта: відхилено, бо вона не відображає локальний контекст.
- Публікація операційних даних в OSM: відхилено через ризики безпеки та невідповідність призначенню OSM.
- Залежність від публічних OSM tile-серверів як production-SLA: відхилено; для production потрібен окремий постачальник або власна інфраструктура.

## Consequences

Карта має версії, рівні доступу, атрибуцію джерела та підтвердження об’єктів. Кожне картографічне представлення містить атрибуцію OpenStreetMap і відповідної ліцензії.

## Security considerations

Публічні, службові та чутливі дані розділяються. Службові й чутливі координати, контакти, залежності інфраструктури та властивості не публікуються автоматично й не передаються до OSM. API public-представлення виключає sensitive-властивості.

## OpenStreetMap licensing and attribution

Імпортований OSM-контент зберігає зовнішній ідентифікатор, джерело, дату та атрибуцію. Відображення повинне містити «© OpenStreetMap contributors» і посилання на ліцензійні умови ODbL.
