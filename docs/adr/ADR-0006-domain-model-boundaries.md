# ADR-0006: Межі доменної моделі

**Статус:** прийнято · **Дата:** 2026-07-24

Community є коренем агрегату. Risk, Preparedness, Simulation, Evaluation та Improvement розділені сервісними межами; API є адаптером і не містить методологічних розрахунків. Це зберігає аудитованість та дозволяє змінювати формули лише після окремого ADR.
