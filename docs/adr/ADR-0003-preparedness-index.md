# ADR-0003: Індекс готовності як пояснюване узагальнення

**Статус:** прийнято для Foundation v0.1 · **Дата:** 2026-07-24

## Контекст

Громадам потрібен спосіб бачити прогрес, але один непрозорий бал може створити хибні порівняння або стигматизацію.

## Рішення

CPI проєктується як пояснюване, контекстне узагальнення кількох підтверджених вимірів. Він завжди супроводжується CPP, джерелами, обмеженнями та рівнем упевненості. Формулу не затверджено до пілотної валідації.

## Альтернативи

- Один публічний рейтинг громад: відхилено через ризик хибного використання.
- Лише якісні описи без вимірів: відхилено, бо ускладнює відстеження змін.

## Наслідки

Команда оцінювання має визначити виміри, правила якості даних і процедуру оскарження або перегляду профілю.
