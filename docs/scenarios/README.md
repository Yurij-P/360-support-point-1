# Документація сценаріїв TPS360

Цей каталог призначений для опису симуляційних сценаріїв, їхніх навчальних цілей, передумов, ролей, подій, матеріалів фасилітації та підсумків.

**Статус: стартовий каркас.** Сценарії ще не створені, не протестовані та не валідовані.

## Мінімальний склад сценарію

1. Ідентифікатор, назва, версія й статус;
2. Мета, цільова аудиторія та компетентності;
3. Контекст, припущення й межі;
4. Ролі учасників та хід подій;
5. Матеріали фасилітатора і критерії дебрифінгу;
6. Ризики, джерела та історія переглядів.
